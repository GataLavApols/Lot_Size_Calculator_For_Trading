How it works

  • Forex standard lot = 100,000 units. Indices 1.0 lot = contract size 1 ($1 per point).
  • Gold (XAUUSD): 1 lot = 100 oz, 1 pip = 0.1 → $10 / pip / lot. Silver: 1 lot = 5,000 oz → $50 / pip / lot.
  • Pairs ending in USD need no price. All others need one conversion price from your broker.
